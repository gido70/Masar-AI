# Masar AI — V5.6 Review

الفرع الحالي يوحّد منصة «مسار AI — الدليل التنفيذي الذكي» مع ملف أوراق العمل المعتمد حتى الخطوة **17/24**.

## الحالة الحالية

- الخطوات 1–17 موثقة ومتطابقة بين فهرس المشروع، بوابة المدرب، والمنصة التنفيذية.
- الخطوات 18–24 تبقى دون عناوين أو إجابات إلى أن يشرحها المدرب.
- مختبر التنفيذ النشط هو الفيديو، مع CapCut وRunway فقط.
- السعر والدفع غير معتمدين؛ الدعوة الحالية هي إلى المسار التجريبي أو قائمة التجربة المبكرة.
- بوابة المدرب تعرض التقدم والمخرجات والأدلة والإصدارات والاختبارات والتعليقات فقط، ولا تعرض نصوص استعداد المالك أو خطط المنافسة.

## ملفات الواجهات

- `index.html`: منصة مسار AI التنفيذية.
- `docs/masar-ai-project-index.html`: الفهرس الداخلي الحي للخطوات والبنية.
- `trainer.html`: بوابة متابعة المدرب بصلاحية المشاهدة والتعليق.

## خط الأساس التاريخي

نسخة اختبار مركزة على مسار الفيديو فقط.

## ما تغيّر في V5.2
- تصحيح سياسة الثقة: لا ادعاء بأن الصوت أو الموقع مسارات مكتملة.
- قياس حقيقي قبل البداية: معرفة الأداة + مستوى الثقة من 1 إلى 5.
- إبراز حالة التحقق لكل أداة: مختبر فعليًا مقابل مراجعة توثيق فقط.
- إضافة أول نتيجة فعلية لاختبار CapCut داخل معرض النتائج، مع الدروس والقصور كما هي.
- إمكانية تنزيل سجل اختبار JSON دون بيانات شخصية بدل ادعاء وجود تخزين مركزي.
- تكبير هوية «مسار AI» في الترويسة لتكون أوضح وأكثر حضورًا.

## نطاق النسخة
الفيديو فقط، أداتان فقط: CapCut وRunway. بقية المجالات رؤية مستقبلية وليست مسارات نشطة.


## تحديث V5.2
- تبسيط أسئلة مسار الفيديو وشرح كل سؤال بمثال عربي واضح.
- تكبير هوية «مسار AI» ووضعها بوضوح في منتصف الترويسة.
- عدم نشر الفيديو التجريبي السابق؛ معرض النتائج ينتظر اختبارًا جديدًا لنفس الموضوع في CapCut وRunway.
- تنظيف تكرار CSS الذي تسرب إلى قالب تنزيل Word.
- لا توسع إلى الصوت أو الموقع في المختبر النشط.
