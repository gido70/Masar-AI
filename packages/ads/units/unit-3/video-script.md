# الوحدة 3 · اختيار الفكرة والرمز البصري — سيناريو الفيديو (نسخة 1 · 23 أكتوبر 2026)

- **القاعدة:** كل عنصر يظهر على الشاشة يذكره الصوت باسمه لحظة ظهوره · كل لقطة رمزية يشرح الصوت معناها.
- **المدة المتوقعة:** نحو 3 دقائق (نحو 320 كلمة).
- **الصوت:** George · **سراج المتزامن:** المشاهد 1 و6 و8، نحو 40 ث ≈ 2.50$.
