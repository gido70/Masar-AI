- فهم الحاجة.
- تضييق الخيارات.
- سبب الترشيح.
- Prompt جاهز.
- إعدادات مفاهيمية أساسية.
- رابط الأداة الرسمي.
- رابط التوثيق الرسمي.
- تاريخ آخر تحقق.

- أسماء القوائم والأزرار.
- مسار النقر.
- تغييرات الواجهة.
- التنفيذ النهائي.
