# مصنع فيديو مسار (المرحلة 1)

ينتج فيديو كاملًا من ملف وصف واحد: البطاقات، والظهور التدريجي، وتركيب المحتوى على شاشة المقدّم، والترجمة النصية، والمونتاج، والصوت.

## التشغيل
```bash
pip install -r studio/requirements.txt
python -m playwright install chromium     # مرة واحدة
python studio/make_video.py productions/<اسم-الفيديو>/spec.json
```
المتطلبات: Python 3 و ffmpeg. المشاهد المنتَجة تُحفظ في `_work/` وتُعاد استخدامها؛ لإعادة إنتاج كل شيء: `FORCE=1`.

## إنتاج فيديو جديد
1. أنشئ مجلدًا: `productions/<اسم>/`.
2. ضع فيه: الصوت الكامل (بصوت George)، ومقاطع المقدّم من InfiniteTalk إن وجدت.
3. اكتب `spec.json` (انظر `productions/video-unit-1/spec.json` مثالًا).
4. شغّل المصنع.

## ملف الوصف (spec.json)
| الحقل | المعنى |
|---|---|
| `label` | اسم الحقيبة والوحدة أعلى البطاقات |
| `audio` | أجزاء الصوت بالترتيب: `file` ومعه `start`/`end` اختياريًا |
| `segments` | المشاهد بالترتيب |

**أنواع المشاهد:**
- `presenter`: فيديو المقدّم (`video`) + محتوى الشاشة (`screen`: `kicker`، `title`، `lines`، `button`، `foot`) + `captions` بتوقيت داخل المقطع.
- `card` + `duration` + `card`:
  - `grid`: عناصر مرقّمة `items: [[عنوان, شرح], ...]`، و`cols`.
  - `tree`: صفوف «غرض ← شكل» `rows`، و`note` جانبية.
  - `rule_bars`: لافتة قاعدة `rule {big, text, note}` + أشرطة `bars: [[اسم, قيمة, نسبة 0–1], ...]`.
  - `cards`: بطاقات ملونة `items: [[عنوان, قيمة, green|amber|red], ...]` + `warning`.
- `end`: بطاقة الختام `title`، `sub`، `duration`.

`[[كلمة]]` في أي عنوان تُلوَّن بلون التأكيد.

## التزامن (من الإصدار 1.8)
- **`audio` داخل كل مشهد:** `{"file", "start", "end"}`. مدة البطاقة = طول مقطعها الصوتي + `hold` (افتراضيًا 1 ثانية ثبات قبل الانتقال). مدة المقدّم = مدة فيديو المقدّم.
- **`reveal_at`:** في `card` وفي `screen` للمقدّم، توقيت ظهور كل عنصر بالثواني من بداية المشهد، بالترتيب. العنوان والـ kicker يظهران من البداية.
  - العناصر التي تظهر: `grid` العناصر، `tree` الصفوف ثم `note`، `rule_bars` اللافتة ثم الأشرطة، `cards` البطاقات ثم `warning`، `screen` الزر ثم `lines` ثم `foot`.
  - التوقيت = بداية نطق العنصر − 0.1 ثانية (تُستخرج من `silences()`).
- **فحص إلزامي قبل الإنتاج:** عدد التوقيتات = عدد العناصر، ثانيتان على الأقل لكل عنصر، و3 ثوانٍ للعنصر الأخير قبل الانتقال، وصوت المقدّم لا يتجاوز فيديوه. أي خلل يوقف الإنتاج (للتجاوز: `NO_STRICT=1`).
- **الترميز النهائي:** `yuv420p` و High، ليعمل على الهواتف والمتصفحات.
- **الذاكرة المؤقتة:** اسم كل مشهد في `_work/` يحمل بصمة محتواه، فأي تعديل في المشهد يعيد إنتاجه تلقائيًا.
- يُكتب `_work/timeline.json` بأوقات كل مشهد وكل ظهور للفحص.

## قواعد مجرّبة
- لا تشكّل الكلمات الدخيلة في نص الصوت (فيديو، كاميرا)؛ يشدّد George عليها.
- القراءة على شكل قائمة أبطأ من النثر: نحو 1.45 كلمة في الثانية (مقاسة في الوحدة 1) مقابل 1.85 للنثر.
- مقاطع المقدّم تُقص من الصوت الكامل عند الوقفات، وتُرفع إلى InfiniteTalk على `studio/assets/presenter-screen.png`.
- الهوية في `THEMES` داخل `make_video.py`؛ كل حقيبة يمكن أن تضيف هويتها.
