# الفيديو السريع: خدمة شخصية لصاحب المشروع (19 أكتوبر 2026)

> فيديو قصير (حتى دقيقة) لأي غرض خارج الحقائب: مناسبة، أو صديق، أو فكرة عاجلة. لا يمر ببوابات الحقائب الخمس، لكن يبقى التقدير قبل الصرف وسقف التكلفة.

## كيف تطلبه
افتح محادثة جديدة في مشروع مسار، واكتب:

```
فيديو سريع:
- الغرض والجمهور:
- المدة: (15 ث / 30 ث / دقيقة)
- الإطار: عمودي للهاتف / أفقي
- الشخصية: سراج / امرأة / صورة أرفعها / بلا شخصية
- الصوت: George / صوت امرأة / بلا كلام (موسيقى ونص)
- النص: أكتبه أنا / تكتبه أنت
- الأسلوب: مقدّم يتكلم / مشاهد متحركة / الاثنان
- السقف: (مثل 3$)
```

## ما يحدث بعدها
1. Claude يكتب النص والسيناريو المختصر ويعرضهما مرة واحدة.
2. Claude يختار الطريق ويكتب التقدير (المال والزمن).
3. التنفيذ بحسب الطريق أدناه، ثم ملف mp4 جاهز في المحادثة.

## الطرق
| الأسلوب | الطريق | من يولّد | تكلفة الدقيقة تقريبًا |
|---|---|---|---|
| مقدّم يتكلم (ثابت الخلفية) | صورة + صوت ← WaveSpeed InfiniteTalk | Claude | نحو 3.8$ |
| مشاهد متحركة بلا كلام على الشاشة | Flow (أوصاف من Claude) + تعليق صوتي | صاحب المشروع في Flow، والباقي Claude | رصيد Pro + سنتات |
| مشاهد متحركة يتكلم فيها الشخص | Flow للحركة + صوت + WaveSpeed فيديو إلى فيديو | صاحب المشروع في Flow، والباقي Claude | رصيد Pro + نحو 3.8$ |
| مشاهد متحركة آليًا بالكامل | Gemini API (Veo Fast) + صوت + مزامنة | Claude | نحو 6$ وأكثر مع الإعادة (احتياط) |

## القواعد
- تقدير قبل كل تشغيل، وسقف لا يُتجاوز.
- الصوت العربي من ElevenLabs دائمًا، لا من نموذج الفيديو.
- لا وجه شخص حقيقي دون إذنه، ولا انتحال شخصية عامة.
- المخرجات في productions/quick/<التاريخ-الاسم>/ ولا تختلط بالحقائب.
