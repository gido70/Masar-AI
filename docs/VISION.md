# وثيقة الرؤية

## المنتج
منصة عربية إرشادية تنفيذية لاستخدام الذكاء الاصطناعي.

## القيمة
اختصار التشتت بين الأدوات وتحويل الحاجة إلى مسار قابل للتنفيذ.

## المستخدم
لا يُطلب منه معرفة اسم الأداة. يمكن أن يكون باحثًا أو معلمًا أو مهندسًا أو صاحب مشروع؛ نقطة البداية هي المهمة.

## سياسة الجودة
1. لا ينشر مسار غير مكتمل.
2. كل مسار ينتهي بنتيجة وفحص جودة.
3. كل أداة لها سبب اختيار وبديل.
4. كل معلومة متغيرة لها تاريخ مراجعة.
5. الطلبات غير المغطاة تسجل كفجوات معرفة.
6. مراجعة بشرية قبل اعتماد تحديثات الرادار.
